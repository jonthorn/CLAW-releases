# CLAW Releases

CLAW is an independent, proprietary painting application. It is free to use on Windows 11 x64. You can paint offline without an account.

See [Releases](../../releases) for the Windows installer, SHA-256 manifest and version-specific release notes. CLAW’s public beta uses manual installer downloads.
