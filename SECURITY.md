# CLAW Security Policy

## Supported version

This policy covers CLAW 0.0.16 early beta for Windows 11 x64. Reports about the current official beta are welcome.

## Report a vulnerability privately

**Private security contact** · [clawpainting.support@gmail.com](mailto:clawpainting.support@gmail.com)

Email Jan Trněný with “CLAW security report” in the subject. Include the CLAW and Windows versions, affected feature, observed impact and enough detail to understand the issue. If a sample is needed, start with a description and ask how to share it safely. Keep credentials, private artwork and other people’s personal data out of your report. Please coordinate disclosure by email before sharing sensitive details publicly.

The developer aims to acknowledge reports when able and will share follow-up when available. Look for verified fixes and any steps for users in official release notes or security advisories. Automatic online updates are disabled in 0.0.16. Any applicable statutory reporting duties take precedence over disclosure coordination.
